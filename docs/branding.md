# Branding

Name: **Foresprint**. Logo: a timeline of sprints, two finished blocks and a dashed block for
the forecast, on an indigo square with a violet diagonal.

| File | Use |
| --- | --- |
| `docs/assets/logo.svg` | Square logo (app icon, avatar) |
| `docs/assets/logo-wordmark-light.svg` | Logo with name for light backgrounds |
| `docs/assets/logo-wordmark-dark.svg` | Logo with name for dark backgrounds |

The app icon (browser tab, launchers) is drawn in `src/foresprint/icon.py` with the same
shapes and colors.

| Role | Color |
| --- | --- |
| Primary (indigo) | `#5b5bf0` |
| Secondary (violet) | `#a24df0` |
| Forecast (mint) | `#17c3a0` |
| Highlight (sun) | `#ffc233` |

Display font for the wordmark: Iosevka (OFL), falling back to any monospace font.
